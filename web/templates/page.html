Espalier

A native Git client for the Mac. Keep track of your branches, stage individual lines, and clean up your commits before you push.

A clear view of your repository.

In Graph view, each branch gets its own color so you can actually follow merges and parallel work. Switch to Simple when you just want a flat list of commits on your current branch.

  • Graph or Simple view for one branch or the whole repo
  • Commit Info for parents, branches, co-authors, and trailers
  • Branch comparisons showing which commits are ahead or behind

Stage only what belongs in the commit.

Check off whole files, individual hunks, or single lines directly in the diff, and discard leftover edits you don't want to keep.

  • Line-by-line stagingCheck off the exact lines or hunks you want to commit, and discard the rest.
  • Unified or split diffsHide whitespace changes, wrap long lines, or expand context around an edit.
  • Image diffsCompare images using 2-Up, Swipe, Onion Skin, or Difference on a transparency checkerboard.
  • Quick fixesAdd co-authors, amend your last commit, or undo it while keeping your working changes.

Clean up commits without interactive rebase.

Tidy your local branch before pushing by dragging commits where they need to go. Espalier checks for conflicts ahead of time, shows progress as it works, and lets you undo if you change your mind.

  1. SquashDrag one commit onto another to combine them.
  2. ReorderDrag a commit between two others to change the sequence.
  3. Cherry-pickDrag a commit onto any branch in the sidebar.
  4. Merge or rebasePress ⇧⌘M to merge, squash and merge, or rebase with a conflict check first.
  5. UndoPress ⌘Z to revert a squash, reorder, or cherry-pick.

GitHub pull requests in the sidebar.

Sign in to GitHub.com or GitHub Enterprise to keep open pull requests right next to your branches. You can check them out, watch CI checks or re-run failed ones, and get notified when a review comes in.

If GitHub push protection blocks a push over a leaked secret, Espalier shows you what triggered it and where.

Optional AI, using your own keys.

If you want help drafting commit messages or resolving merge conflicts, connect OpenAI, Anthropic, Azure OpenAI, or a local model on your Mac. Keys stay in your Keychain, and Espalier always asks before talking to a new provider.

There is no Espalier AI service—if you don't add a provider, nothing is ever sent.

Everything else you'd expect

  • Git included

    Ships with Git 2.53, Git LFS, and Git Credential Manager built in, so there's nothing extra to set up.

  • Worktrees and stashes

    Check out any branch or pull request into its own worktree, or stash uncommitted work with ⇧⌘S.

  • Commit signing

    Uses your existing GPG or SSH setup to sign commits, with clear error messages if signing fails.

  • Editor and terminal handoff

    Jump straight to Xcode, VS Code, Zed, Cursor, JetBrains IDEs, Terminal, iTerm2, Ghostty, Warp, and dozens more.

  • Command line tool

    Run espalier open or espalier clone owner/name to launch repos directly from your shell.

  • Full keyboard control

    Every action lives in the menu bar with shortcuts for common tasks, including ⇧F10 to open context menus on any row.

  • VoiceOver and accessibility

    Full VoiceOver support for the commit graph and diffs—with rotors for branches, tags, and changes—plus Reduce Motion support.

  • Automatic updates

    Checks for updates daily and verifies cryptographic signatures before installing.

No accounts. No telemetry.

Espalier doesn't require an account and doesn't collect analytics, telemetry, or crash reports. Your tokens, API keys, and saved passwords stay in your Mac's login Keychain.

Network connections are limited to

  • Your Git remotesWhen you fetch, pull, or push, plus background fetches to keep your status up to date.
  • GitHubAfter you sign in, to load pull requests, check runs, and notifications.
  • GitHub's avatar serviceTo load profile pictures, which sends the email addresses of commit authors you view.
  • AI providers you configureOnly after you explicitly approve the first request to each provider.
  • updates.abdeen.industriesOnce a day to check for and download signed app updates.

Free and open source.

An espalier is a tree trained to grow flat along a trellis, with its branches laid out so every one is easy to reach. The app started as a native Swift port of GitHub Desktop and still shares much of its underlying Git plumbing and test suite, built out into a dedicated Mac interface. It's free under the MIT license. Espalier is an independent project, not affiliated with or endorsed by GitHub.
